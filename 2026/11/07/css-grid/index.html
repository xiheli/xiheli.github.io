CSS Grid 的 auto-fill 与 auto-fit，到底差在哪

两个关键字只差一个词，效果却完全不同：一个保留空轨道，一个把空轨道折叠掉。用一张图和一个表格就能记住。

2026-11-07 · 周六 · 约 1 分钟 · 313 字

写分类卡片网格时又犹豫了一下该用 auto-fill 还是 auto-fit，索性把区别写清楚。

一句话版本

  • **auto-fill**：尽可能多地放轨道，哪怕没有元素填进去，空轨道也占着位置。
  • auto-fit：先按 auto-fill 算，然后把空的轨道折叠成 0，剩下的元素平分空间。

代码

把 auto-fill 换成 auto-fit，元素少的时候卡片会明显变宽，因为空轨道不再占位。

什么时候用哪个

关键字 元素不足时的表现 适合的场景
auto-fill 保持列宽，右侧留白 希望卡片宽度稳定、不随数量跳动
auto-fit 卡片撑满整行 卡片数量少时想填满容器

一个容易忽略的点

两者的 minmax() 里如果写的是固定值（比如 272px），auto-fit 拉伸后单张卡片会变宽；如果写的是 minmax(272px, 1fr)，卡片会先占满再平分，看起来更整齐。

我的选择

分类卡片用 auto-fill：分类数量以后会变，但卡片宽度不该跟着变来变去。真正需要撑满的地方（比如只有两三个标签的标签云）再用 auto-fit。

记不住的时候就回到那句话：auto-fill 保留空位，auto-fit 折叠空位。
