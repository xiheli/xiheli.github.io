关于

这里是一个长期施工的个人记录站：学习日志、项目复盘、源码笔记，以及一些没什么用的想法。

这个站在记什么

我把日常里值得留下来的东西拆成几类：

  • 学习日志 —— 读完一本书、上完一门课、啃完一篇论文之后，用自己的话写一遍。
  • 项目记录 —— 每次迭代做了什么、为什么这么做、哪里返工了。
  • 源码阅读 —— 读框架和库的源码，顺手把关键调用链画出来。
  • 工具与效率 —— 环境配置、脚本、自动化，省下来的时间要记一笔。
  • 随笔 —— 跟代码无关的那些。

为什么用日志的形式

写日志的好处不是给别人看，是给三个月后的自己看。三个月后的我大概率已经忘了当时为什么那样写，而一篇记录能省下一整天的重新摸索。

所以这里的每一条都尽量朴素：日期、分类、几句话、必要时附一段代码。不追求篇幅，只追求「下次还能看懂」。

关于我

这里可以写一两句自我介绍：你的方向、正在学什么、怎么联系你。这些记录如果帮到你，欢迎到 GitHub 找到我。

这个站是怎么搭的

Hexo 生成静态页面，部署在 GitHub Pages 上。主题是为「日志」专门写的 Chronicle：首页是一条按月分组的时间轴，顶部分类按钮可以即时筛选，右上角能搜索全站内容。想改颜色、导航或者分类描述，都在 _config.chronicle.yml 里。

这段文字可以直接在 source/about/index.md 里改，换成你自己的介绍就行。
